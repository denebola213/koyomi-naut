# UI 構造（入力ゾーン／結果ゾーン・見た目の原則）

画面構造の原則。アイコンの形・色は `timeline-icon.md`、赤テーマは `red-theme.md` 参照。

## ゾーン分離

- 画面は「入力ゾーン」（場所・日付の指定）と「結果ゾーン」（確定した条件・出没・薄明・軌道）
  に分ける。
- 結果ゾーンはタブで「出没・薄明」（既定）と「星空のようす」（全天図）の2ビューに分ける。
  タブの表示名を変えても内部 ID（`tab-sky` / `panel-sky` / `skyChart`）とハッシュは変えない。
- 入力控件を結果ゾーンに入れない、結果表示（座標・日付など）を入力セクション内に置かない。
- 結果ゾーン先頭に「確定した条件」を自動表示し、結果側で現在の入力値を一目で確認できるようにする。
- 座標入力欄は入力専用。確定座標の表示は結果ゾーン側で行い、入力欄を結果表示として流用しない。
- `scripts/verify-dom.py` が「入力ゾーンに結果 ID が漏れている／結果ゾーンに入力控件が
  漏れている」を検出する（JS が参照する ID が HTML に存在するかも併せてチェック）。

## 見た目の原則

- 影・カード・ボックスを使わず、罫線と余白で階層を作る。結果ゾーンもボックス化しない
  （背景・罫線なし）。
- ゾーン区分は見出しの太い下罫で作り、入力／結果の横線（`.zone > h2`）は
  `3px solid var(--accent)` で色付けする（ユーザー指定）。
- accent 色はライト `#9a5b00`／ダーク `#d9a94a`／赤テーマ `#de6b6b`（色相は従来の琥珀・赤を維持し、
  輝度だけ下げて夜間の眩しさを抑えた。対地コントラストはライト 4.7／ダーク 8.8／赤 6.2）。
- 装飾（色・罫の強調）を外す依頼が来たときは `styles.css` 全体で `var(--accent)` の残存を
  grep し、見出し下罫など他の宣言も併せて除去する（1箇所の残存が拒否された外観を再現する）。
  逆に色付けを指示された場合はゾーン横線を accent で残す。
- UI 見出しの番号（`1. 場所` 等）を外す依頼では `h3` の数字だけを除去し、
  `README.md` の使い方の手順番号（1. 2. 3.）まで消さない。
